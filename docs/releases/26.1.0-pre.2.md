# 26.1.0-pre.2

## 新增：Windows 桌面端（绿色便携版，x64）

下载 `LanCloud-26.1.0-pre.2-windows-x64.zip`，解压出来直接运行 `lancloud.exe`，
不需要安装，也不需要管理员权限（已内置 VC++ 运行时可再分发副本）。

**系统要求**

- Windows 10 1809（内部版本 17763）及以上，或 Windows 11，**64 位**
- 需要 **WebView2 运行时**：Windows 11 自带；Windows 10 请安装
  [Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)，
  否则「网页登录」「分享浏览」这类内嵌网页打不开（其余功能不受影响）

**桌面端与 Android 的差异**

- 后台传输：桌面端窗口即进程，没有前台服务保活
- 分享：没有系统分享面板，文本走剪贴板、文件用资源管理器定位
  （传输页已完成下载的条目按钮即「打开所在文件夹」）
- 拖拽：支持从资源管理器拖文件进窗口上传；Windows 拿不到拖拽文本，链接请粘贴
- 二维码：只能选图片识别，没有拍照入口
- 设置：「通知权限 / 安装应用 / 忽略电池优化 / 默认打开链接」等只在 Android 显示
- 窗口：默认 850×576、最小 425×445（逻辑像素），启动时居中

## 其他改动

- Windows：修复网盘页同时出现两条滚动条（刷新指示器带来的 widgets 层 RawScrollbar）
- 修复设置 / 关于 / 备份 / 首页等页面滑动时滚动条滑块长度抖动
- 中文字体兜底固定为微软雅黑，避免系统兜底选到日文字形
- 「从备份恢复？」弹窗的复选行铺满弹窗宽度，点按波纹不再被截断
- Android：通知权限 / 安装应用 / 忽略电池优化合并为「管理权限」弹窗
