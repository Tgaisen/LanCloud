# 26.1.0-pre.3

> 安装包命名规则自本版起改为 `lanCloud_平台_版本_架构`。

## 无障碍

面向读屏用户的一批改进（已在华为屏幕朗读上逐项验证）：

- 首页快捷操作栏的按钮补上名称，读屏会读出「打开链接 / 识别二维码 / 传输 / 收藏」
  （带角标时并读数量），不再只读「按钮」
- 置灰的多选操作项有了自己的语义节点与「已停用」状态，
  焦点落到窗口最外层时不会再念出「下载」
- 「快速访问 / 最近使用」的标题与展开按钮合并为一个可点区域，
  读作「收起快速访问」「展开快速访问」
- 长按进入多选会播报一次「进入多选」；切页面不再误播报，继续加选其它条目也不重复
- 多选选中的条目标注为「已选中」
- 返回按钮、退出搜索等按钮补上名称
- 登录 / 首启 / 关于页的应用图标、二维码图等装饰元素不再被聚焦朗读
- 浅色主题正文色对比度 4.2:1 → 8.9:1；若干列表 / 按钮点击区 40dp → 48dp

## 动效（前庭敏感友好）

- 尊重系统「移除动画 / 减弱动态效果」以及读屏软件接管交互：
  页面转场、列表入场、路径栏展开等装饰性动画直接跳过
- 首页切换 page 视图、顶栏 / 底栏收起也不再播放动画
- 修掉部分 ROM（如华为）的无障碍「移除动画」只改 `window` / `animator`
  动画缩放、Flutter 引擎读不到的问题：改为直接读系统动画缩放，并实时跟随设置变化

## 多选

- 网盘页进入多选后隐藏行内 ⋯，但保留占位，条目高度不再跳变
- 传输页顶栏新增「多选」入口（位于「清除已完成」左侧）

## 修复

- 分享文件夹浏览页：内容不足一屏时会自动补页，失败自动重试，
  不再一直停在「加载下一页」转圈；确实失败时给出「重试」入口
