# LanCloud 开发路线图

## v0.2 体验重构（已完成，剩昵称显示）

- [x] 网盘目录分页加载（默认首页 + 滑到底加载下一页，可切换"全部加载"）
- [x] 网盘目录缓存（返回上一级不重载，可在设置开关）
- [x] 搜索改为工具栏内联 SearchView（替换弹窗）
- [x] 路径栏独立一行，根目录显示"根目录"
- [x] 悬浮按钮改为"添加"菜单：新建文件夹（名称 + 简介）、上传文件
- [x] 点击工具栏标题区域回到列表顶部
- [x] 返回逻辑：默认页再按返回退出应用，其他视图返回默认页；传输中退出需确认
- [x] 传输页按"进行中/已结束"分组
- [x] 底栏传输按钮加任务数量角标
- [x] 网盘文件显示"已下载"标记；应用内删除文件时同步清除
- [ ] 账号显示昵称（网页解析，失败回退 UID）
- [x] 修复冷启动状态栏颜色与背景不一致

> 说明：v0.2 的批量操作先实现了删除/下载/分享/收藏；移动、批量改简介、
> 批量设密码随 v0.3 的属性菜单一起做。排序已改为菜单项（Segmented 按钮并入 v0.4）。

## v0.3 分享与批量（已完成）

- [x] 文件属性弹窗：属性头部、简介、分享链接、二维码、下载、收藏
- [x] 文件夹属性弹窗：完整简介、统计信息（文件数/大小）、二维码、收藏
- [x] 文件操作弹窗（⋯）与属性弹窗（点击）分离
- [x] 批量操作：删除、下载、分享、收藏、改简介、设访问密码
- [x] 文件夹统计改用网页信息页（myfile.php），不再遍历子目录
- [x] 返回逻辑四级优先级：多选 > 上级目录 > 启动页 > 退出
- [ ] 分享文件夹浏览页的多选批量（待做）
- [ ] 统一 WebView 页（个人中心/分享），注入 Cookie 免二次登录（待做）

## v0.4 设置与外观（进行中）

- [x] 深浅色模式、OLED 纯黑、MD3 预设配色
- [x] 横滑切换四个视图（可开关）
- [x] 行为：默认启动页、目录缓存开关、自动加载剩余内容
- [x] 连接：网络请求间隔（默认 300ms）、上传/下载并发数
- [x] 高级覆盖项：网盘域名（pc/up）、自定义 UA
- [x] 顶栏滚动变色（四视图统一，50ms）
- [x] 滑动隐藏顶栏/底栏（顶栏/底栏收起、收起类型、MD3 悬浮底栏；网盘页顶栏 sliver 化，路径栏并入顶栏底部随顶栏一起收起）
- [x] 独立设置页（分类 + 二级 + 搜索；顶底栏收起改为独立存储键）
- [x] 过渡动画开关：目录切换、列表出现动画（网盘页条目错峰淡入，可在设置关闭）
- [x] 高级覆盖项：分享链接域名、上传域名

## v0.5 高级能力

- [ ] 后台传输（前台服务 + 常驻通知，合规方式）
- [ ] 通知栏传输进度与完成提醒（Android 13+ 通知权限）
- [ ] 批量操作通知栏进度
- [ ] WebDAV 自动备份 / 本地备份恢复（Cookie 默认不备份）
- [ ] 显示/导出 Cookie（生物识别 + 风险提示）
- [ ] 分享目标：从其他应用分享链接或文件到 LanCloud
- [ ] 权限管理：相机（扫码）、安装应用（打开 APK）、电池优化
- [ ] APK/常见文件类型的系统打开与安装流程

## v1.0 合规与开源

- [ ] 用户协议 / 隐私政策 / 首次启动同意
- [ ] 关于页：版本、开源许可、协议入口
- [ ] LICENSE 与参考项目署名（见 docs/PROTOCOL.md）
- [ ] README 完善（功能、截图、构建说明、免责声明）

## 明确不做

- 绕过官方单文件大小限制、伪装上传后缀等规避功能
- 转存他人分享到自己网盘
- 非合规的隐蔽保活
