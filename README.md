# LanCloud

蓝奏云第三方客户端（自用）。基于蓝奏云非官方接口实现，仅供个人使用。

## 安装

1. 按手机架构选一个装（不确定就选 arm64）：
   - `outputs\LanCloud-0.2.4-arm64.apk`：绝大多数手机（2016 年后的机型）
   - `outputs\LanCloud-0.2.4-arm32.apk`：很老的 32 位机型
2. 点击安装，遇到提示时允许「安装未知来源应用」
3. 打开 App，按提示粘贴 Cookie 登录

## 登录方式

推荐用 **网页登录**：在 App 的登录页点「网页登录（推荐）」，会在 App 内打开蓝奏云官方页面。
登录过程中遇到滑块验证正常完成即可，登录成功跳到网盘页面后 App 会自动读取并校验 Cookie，保存账号。

如果网页登录遇到问题，可以用下面的手动方式。

### 手动获取 Cookie

1. 用浏览器打开并登录蓝奏云官网（pc.woozooo.com）
2. 按 F12 打开开发者工具，切到 Network（网络）面板，刷新页面
3. 随便点一个请求，在 Request Headers 里找到 `Cookie`
4. 复制整段内容（需要包含 `ylogin=...` 和 `phpdisk_info=...`）
5. 粘贴到 App 的登录框里

> Cookie 只保存在手机本地，使用系统加密存储，不会上传到任何第三方服务器。
> Cookie 有效期较长，失效后重新粘贴一次即可。

## 已实现（0.2.0）

- 登录：应用内网页登录（自动抓取 Cookie，支持滑块验证）、手动粘贴 Cookie，多账号保存与切换
- 网盘：面包屑路径、网格/列表视图、排序、弹出式搜索（当前目录）
- 管理：新建文件夹、批量选择、删除（移入回收站）、复制分享链接
- 上传：多选文件、进度显示、队列（免费账号单文件 ≤100MB）
- 下载：分享链接解析下载、进度显示、完成后用系统应用打开
- 分享：打开他人的文件/文件夹分享，支持提取码、二级子文件夹
- 首页：最近使用（跟随账号）、我的收藏（全局，不随账号变化）
- 我的：网页版入口（回收站、资料修改）、下载目录设置、清空记录
- 适配：手机底栏、平板侧边栏，网格列数自适应

## 重新构建

```powershell
tools\flutter.cmd build apk --release --split-per-abi
```

产物在 `build\app\outputs\flutter-apk\`，按 ABI 分成三个 APK：
`app-arm64-v8a-release.apk`（推荐）、`app-armeabi-v7a-release.apk`、`app-x86_64-release.apk`。
分架构包体积约为通用包的一半，装机时按手机架构选择即可。
